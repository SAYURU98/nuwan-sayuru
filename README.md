# nuwan-sayuru

Personal portfolio of Nuwan Sayuru. Static site in `public/` with Cloudflare Pages Functions in `functions/`.

- Hosting: Cloudflare Pages (Git integration, no build step, output `public`)
- Data: Cloudflare D1 `nuwan-portfolio-db` (binding `DB`), KV `nuwan-portfolio-files` (binding `FILES`) for the CV
- Admin: `/#admin`
- Schema: `schema.sql`
